# Guards

Guards describe workflow-scoped rules, gates, policies, or control points.

## Common Tasks

- Create a new guard.
- Edit the guard description and classification fields.
- Delete a guard that is no longer needed.

## Important Behavior

- Guards shown in the dashboard belong only to the active workflow.
- Guard changes use the same right-side drawer pattern as other sections.
- Deleting a guard removes it from the current workflow context only.
- Guards can be linked from Interaction Components.

## Tips

- Use names and descriptions that state what the guard checks.
- Use classification to group related guard types.
- Review linked components before deleting a guard.
