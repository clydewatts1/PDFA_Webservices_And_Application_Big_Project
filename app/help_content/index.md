# PDFA Help

Use the Help drawer to see guidance for the dashboard section you are currently viewing.

## Practical Tasks

- Create or select a workflow before using the dashboard.
- Use section drawers to create or edit records.
- Use `Swap Workflow` to move to another context without signing out.

## Sections

- Workflows: create, update, delete, and switch workflow context
- Roles: manage workflow-scoped human or system roles
- Guards: manage workflow-scoped rules and control points
- Interactions: define the interaction records that belong to the active workflow
- Interaction Components: connect interactions to roles, guards, and directions

## Notes

- You must be signed in and have an active workflow selected to use the dashboard.
- The sign-in form requires a username and password, but those values are not yet validated against an identity provider.
- If a section-specific help file is missing, PDFA shows this index page instead.
