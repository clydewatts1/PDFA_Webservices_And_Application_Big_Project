# Summary

This directory contains the original version 1 specifications for the PDFA Project. This was done using speckit to the agentic code LLM . The specifications in this directory were used to guide the development of the project and to ensure that all development was done in accordance with the constitution. The specifications in this directory are not normative and are not intended to be used as a source of truth for the project. The specifications in this directory are intended to be used as a reference for the development process and to provide context for the development activities. The specifications in this directory may be updated as the project evolves, but all changes must be made through the Spec Kit workflow and must be approved by the project stakeholders.

The author realised that this was not a viable approach for the following reasonns:

1: The author did not learn anything other than how to use speckit to generate documentation and requirements. The 3tier architecture and the constitution were generated by speckit and the author did not have a deep understanding of why they were the way they were. The author was not able to make informed decisions about the architecture or the constitution because they did not have a deep understanding of them.

2. The project would not have worked with Python Anywhere because of the limitations of the hosting environment. The project required a WSGI-compatible hosting environment and Python Anywhere does not support WSGI.
