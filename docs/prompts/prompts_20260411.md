Part 4: Help System & Documentation

1. Storage Strategy

Help Content Folder: Create app/help_content/.

File Format: Markdown (.md).

Naming Convention: context-[entity_name].md (e.g., context-roles.md, context-interactions.md).

2. Interaction Model (Google Side-Panel)

Trigger: Clicking the Help icon in the Header.

UI Pattern: A right-side drawer (Slide-over) similar to the Creator Form.

Context-Awareness:

If the user is on the Roles page, the drawer should automatically load context-roles.md.

If no specific context is found, load a default index.md showing a table of contents.

Backend: A route GET /help/<topic> that reads the requested file from the filesystem and returns it as a JSON object containing the rendered HTML.
