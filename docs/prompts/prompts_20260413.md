Frontend: app/static/js/main.js handles drawer logic but needs to intercept form submissions.

Task:

Frontend Update: Modify main.js to intercept the workflow-drawer-form submission. It should use the fetch() API to send a JSON payload to /api/workflows instead of a standard form post.
